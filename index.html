Projects

Capstone Project
Smart Room Allocation System
A room allocation engine in Java that assigns rooms to requests based on capacity, availability, and priority using four distinct algorithmic strategies.
  • Implemented Backtracking to explore all valid allocation paths and revert invalid assignments in constraint-heavy scenarios.
  • Adapted Best Fit and First Fit strategies from memory management to minimise unused room capacity and maximise slot utilisation.
  • Greedy approach prioritises high-demand requests for near-optimal allocation with improved time efficiency.
  • Clean OOP architecture — separate classes for Room, Request, Allocator, and Strategy.
  • Benchmarked all four algorithms on test datasets: time complexity, accuracy, and wastage metrics.
Java Backtracking Greedy Best Fit First Fit OOP
Research Project
Smart Parking Management System
An automated parking management system capable of detecting, allocating, and releasing vehicle slots without manual intervention, integrating IoT sensor concepts.
  • Modelled system architecture using OOP — ParkingLot, Slot, Vehicle, and ParkingManager classes.
  • Slot allocation logic assigns the nearest available slot to an incoming vehicle and updates lot status in real time.
  • Investigated IoT sensor integration (entry/exit triggers, occupancy detection) aligned with smart city applications.
  • Documented system design, algorithm flow, and scalability improvements in a research report.
